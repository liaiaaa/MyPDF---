# 我的专属安全 PDF 工具箱（MySafePDFToolbox）v1.1

一款 100% 本地离线、源码完全可见、可审计的个人 PDF 处理小工具。
为替代网上来路不明的「PDF 工具箱 uPDF 1.9.0.exe」而专门定制。

## 为什么安全

| 项目 | 说明 |
|------|------|
| 处理方式 | 全部在本机完成，**不联网、不上传任何文件** |
| 代码形态 | 纯 Python 源码，无加壳、无混淆，可逐行审计 |
| 依赖库 | 仅使用知名开源库：PyMuPDF / python-docx / openpyxl / python-pptx / pdfplumber / Pillow / tkinterdnd2 |
| 系统影响 | 不写注册表、不建计划任务、不常驻后台、不静默安装任何东西 |
| 数据边界 | 输入输出都在你指定的本地目录 |

## 怎么启动（推荐顺序）

1. **桌面快捷方式「我的PDF工具箱」** —— 双击即用，**无黑框**（用 pythonw 无窗口运行）。也可以**直接把 PDF / 图片拖到图标上**，松开即打开工具并载入该文件。
2. 工具文件夹里的 **`我的PDF工具箱.lnk`** —— 同上。
3. `启动我的PDF工具箱.bat` —— 备用方案（会短暂出现命令行窗口，正常现象）。

依赖已在本机装好（`E:\software\python`），无需额外操作。

## v1.1 点击体验优化

- **拖拽即用**：把 PDF / 图片直接拖进窗口，自动填入当前功能；拖单个 PDF 自动跳到"PDF 信息"并读取
- **无黑框启动**：改为桌面快捷方式直连 pythonw，不再有命令行窗口
- **进度反馈**：执行时进度条走动 + 状态文字，不会"点了没反应"
- **结果直达**：完成后一键「打开输出目录」/「打开文件」
- **记住目录**：自动记住上次使用的文件夹
- **多文件管理**：合并 / 图片转 PDF 用文件列表，可添加、移除、清空、上移下移
- **智能输出**：输出目录留空时，自动放到源文件所在文件夹

## 功能列表

| 功能 | 说明 |
|------|------|
| PDF 信息 | 页数、大小、加密状态、元数据 |
| PDF 合并 | 多文件按列表顺序合并 |
| PDF 拆分 | 每页一个，或抽取指定页码范围 |
| PDF 压缩 | 图片降采样重压缩，可显著减小体积 |
| PDF 加密 | AES-256 设置打开密码 |
| PDF 解密 | 移除密码保护 |
| PDF 转图片 | 每页渲染 PNG/JPG，可调 DPI |
| 图片转 PDF | 多图合成一个 PDF |
| PDF 转 Word | 提取文本 + 基础表格 |
| PDF 转 Excel | 提取表格数据 |
| PDF 转 PPT | 每页转图片幻灯片 |
| 提取图片 | 导出 PDF 内嵌图片 |

## 关于「去水印」

真正的"去水印"需要破坏性重绘，效果不稳定且易损内容，故未提供。
扫描件/带水印 PDF 建议用「转图片 → 图片编辑 → 转回 PDF」的稳妥流程。

## 安全自检建议

- 可随时用 Windows Defender 扫描本目录：全部源码，不会触发任何告警。
- 若想进一步打包成单个 exe，注意：PyInstaller 单文件无签名 exe 容易被 Defender 启发式误报
  （与本次 uPDF 被检出同类告警），**建议保持源码 + 快捷方式运行方式**，安全且完全可控。
