# 我的专属安全 PDF 工具箱（MySafePDFToolbox）v1.3

一款 100% 本地离线、源码完全可见、可审计的个人 PDF 处理小工具。
为替代网上来路不明的「PDF 工具箱 uPDF 1.9.0.exe」而专门定制。

> 背景：原版 uPDF 在网上流传的多为二次打包版本，被安全软件检出木马
> （Trojan:Win32/Kepavll!rfn）。本项目用 100% 开源库从零实现全部功能，
> 你可以在 Releases 下载免 Python 的 exe，也可以直接审计源码运行。

## 为什么安全

| 项目 | 说明 |
|------|------|
| 处理方式 | 全部在本机完成，**不联网、不上传任何文件** |
| 代码形态 | 纯 Python 源码，无加壳、无混淆，可逐行审计 |
| 依赖库 | 仅使用知名开源库：PyMuPDF / python-docx / openpyxl / python-pptx / tkinterdnd2 |
| 系统影响 | 不写注册表、不建计划任务、不常驻后台、不静默安装任何东西 |
| 数据边界 | 输入输出都在你指定的本地目录 |

## 快速开始

### 方式一：下载免 Python 便携版（推荐，无需任何环境）

去 **[Releases](https://github.com/liaiaaa/MyPDF---/releases)** 下载最新的
`MyPDF工具箱.exe`（约 42MB），**拷到任何 Windows 电脑双击即用**，无需安装 Python。

- 体积说明：已做瘦身优化（59MB → 42MB）。剩余大头是 PDF 引擎（PyMuPDF）+ Python
  运行时，这是"免装 Python + 全部 12 项功能"的物理下限。
- 完整性校验：本机构建的 SHA256 为
  `C34BFD2943519B19046EC0F21E98E0BE8D8B16A6CF579728451FAF54E9687764`，
  下载后用 `certutil -hashfile MyPDF工具箱.exe SHA256` 对比，一致即未被篡改。
- 注意事项：无数字签名的单文件 exe 在个别杀软（尤其国产卫士）的启发式下可能被误报。
  本机 Windows Defender 实测**无威胁**；若他机误报，核对上方 SHA256 后放行即可。

### 方式二：源码运行（可审计，需要 Python）

```bash
pip install -r requirements.txt
python pdf_toolbox.py            # 有拖拽支持
# 或直接双击「启动我的PDF工具箱.bat」
```

## 功能列表

| 功能 | 说明 |
|------|------|
| PDF 信息 | 页数、大小、加密状态、元数据 |
| PDF 合并 | 多文件按列表顺序合并 |
| PDF 拆分 | 每页一个，或抽取指定页码范围 |
| PDF 压缩 | 图片降采样重压缩，可显著减小体积 |
| PDF 加密 | AES-256 设置打开密码 |
| PDF 解密 | 移除密码保护 |
| PDF 转图片 | 每页渲染 PNG/JPG，可调 DPI |
| 图片转 PDF | 多图合成一个 PDF |
| PDF 转 Word | 提取文本 + 基础表格 |
| PDF 转 Excel | 提取表格数据 |
| PDF 转 PPT | 每页转图片幻灯片 |
| 提取图片 | 导出 PDF 内嵌图片 |

## 使用体验（v1.1+）

- **拖拽即用**：把 PDF / 图片直接拖进窗口，自动填入当前功能；拖单个 PDF 自动跳到"PDF 信息"
- **无黑框启动**：桌面快捷方式直连 pythonw，不弹命令行窗口
- **进度反馈**：执行时进度条走动 + 状态文字
- **结果直达**：完成后一键「打开输出目录」/「打开文件」
- **记住目录**：自动记住上次使用的文件夹
- **多文件管理**：合并 / 图片转 PDF 支持添加、移除、清空、上移下移

## 文件结构

```
MyPDF工具箱/
├── pdf_toolbox.py        # 程序入口（保持原启动方式不变）
├── core.py               # 核心功能模块（纯本地 PDF 处理，无 GUI）
├── ui.py                 # 图形界面模块（tkinter）

├── test_all.py           # 全功能自测脚本（22 项）
├── MyPDF工具箱.spec       # PyInstaller 打包配置（生成 Releases 的 exe）
├── 启动我的PDF工具箱.bat  # 备用启动
└── 部署到新电脑.bat       # 一键部署到其它电脑（源码版）
```

## 迁移到其他电脑

- **便携版**：直接下载 Releases 的 exe，拷过去双击即用，零依赖。
- **源码版**：整个文件夹拷贝即走，新电脑上双击「部署到新电脑.bat」自动装依赖 + 建快捷方式。

## 关于「去水印」

真正的"去水印"需要破坏性重绘，效果不稳定且易损内容，故未提供。
扫描件/带水印 PDF 建议用「转图片 → 图片编辑 → 转回 PDF」的稳妥流程。

## 安全自检建议

- 用 Windows Defender 扫描本目录/下载的 exe，全部源码与产物不会触发告警。
- 无数字签名 exe 若被个别杀软启发式误报，以本页公布的 SHA256 为准核验后放行。
