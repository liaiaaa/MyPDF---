# 我的专属安全 PDF 工具箱（MySafePDFToolbox）v1.1

一款 100% 本地离线、源码完全可见、可审计的个人 PDF 处理小工具。
为替代网上来路不明的「PDF 工具箱 uPDF 1.9.0.exe」而专门定制。

## 为什么安全

| 项目 | 说明 |
|------|------|
| 处理方式 | 全部在本机完成，**不联网、不上传任何文件** |
| 代码形态 | 纯 Python 源码，无加壳、无混淆，可逐行审计 |
| 依赖库 | 仅使用知名开源库：PyMuPDF / python-docx / openpyxl / python-pptx / pdfplumber / Pillow / tkinterdnd2 |
| 系统影响 | 不写注册表、不建计划任务、不常驻后台、不静默安装任何东西 |
| 数据边界 | 输入输出都在你指定的本地目录 |

## 怎么启动（推荐顺序）

1. **桌面快捷方式「我的PDF工具箱」** —— 双击即用，**无黑框**（用 pythonw 无窗口运行）。也可以**直接把 PDF / 图片拖到图标上**，松开即打开工具并载入该文件。
2. 工具文件夹里的 **`我的PDF工具箱.lnk`** —— 同上。
3. `启动我的PDF工具箱.bat` —— 备用方案（会短暂出现命令行窗口，正常现象）。

依赖已在本机装好（`E:\software\python`），无需额外操作。

## v1.1 点击体验优化

- **拖拽即用**：把 PDF / 图片直接拖进窗口，自动填入当前功能；拖单个 PDF 自动跳到"PDF 信息"并读取
- **无黑框启动**：改为桌面快捷方式直连 pythonw，不再有命令行窗口
- **进度反馈**：执行时进度条走动 + 状态文字，不会"点了没反应"
- **结果直达**：完成后一键「打开输出目录」/「打开文件」
- **记住目录**：自动记住上次使用的文件夹
- **多文件管理**：合并 / 图片转 PDF 用文件列表，可添加、移除、清空、上移下移
- **智能输出**：输出目录留空时，自动放到源文件所在文件夹

## 免 Python 便携版（推荐带去其他电脑）

**`dist\MyPDF工具箱.exe`** 是打包好的独立程序（约 42MB），**自带全部运行环境**：
对方电脑**不需要装 Python**，把这一个 exe 拷过去双击就能用，功能与源码版完全一致
（含拖拽、进度条、一键打开输出等）。

- **怎么用**：拷 `dist\MyPDF工具箱.exe` 到任意电脑 → 双击运行。
- **体积说明**：已做瘦身优化（从 59MB 降到 42MB，去掉 pdfplumber 全家桶、
  OpenSSL 冗余等）。剩余体积大头是 PDF 引擎（PyMuPDF 约 38MB）+ Python 运行时，
  这是"免装 Python + 全部 12 项功能"的物理下限。
- **验证完整性**（可选）：本机构建的 SHA256 为
  `B48C31F96CE0623C45708B8C7B0BF8F307D131DAB6AE68C26CC36A8A3F2ACA0E`，
  在其它电脑用 `certutil -hashfile 文件 SHA256` 对比，一致即未被篡改。
- **注意事项**：无数字签名的单文件 exe 在某些杀软（尤其个别国产卫士）的
  "启发式"下可能被误报（与当年 uPDF 被报是同类机制）。本机 Defender 实测**无威胁**。
  若他机误报，请核对上方 SHA256 后放行即可。
- **想要更小？** 若不需要"转 Word/Excel/PPT"这三个功能，可做仅含 9 个核心
  PDF 功能的精简版（约 30MB）；若对方电脑装了 Python，源码版几乎零体积。

## 两种版本怎么选

| 版本 | 位置 | 优点 | 缺点 |
|------|------|------|------|
| **便携版 exe** | `dist\MyPDF工具箱.exe` | 免 Python，拷一个文件即用（42MB） | 体积偏大；个别杀软可能误报（可核对哈希放行） |
| **源码版** | 本文件夹 | 完全可审计、永不误报、几乎零体积 | 需目标电脑有 Python |

> 提示：如果目标电脑**没有联网**，便携版 exe 是最好的选择（不依赖网络安装任何东西）。

## 迁移到其他电脑

整个工具就是一个文件夹，**拷贝即走**。到新电脑只需两步：

1. **拷文件夹**：把 `MyPDF工具箱` 整个文件夹拷到新电脑任意位置（U盘/网盘/微信传输均可）。
2. **双击「部署到新电脑.bat」**：脚本会自动——
   - 检测新电脑的 Python（若没有会提示你先装：python.org 下载，安装时勾选 "Add Python to PATH"）
   - 安装全部依赖（需联网，约 1-2 分钟）
   - 在桌面创建「我的PDF工具箱」快捷方式（无黑框）

装完后双击桌面快捷方式即可使用，和这台电脑完全一样。

> 提示：如果新电脑**没有联网**，告诉我，我可以帮你制作一个"离线版"（预下载所有依赖包一起拷走）。

## 关于「去水印」

真正的"去水印"需要破坏性重绘，效果不稳定且易损内容，故未提供。
扫描件/带水印 PDF 建议用「转图片 → 图片编辑 → 转回 PDF」的稳妥流程。

## 安全自检建议

- 可随时用 Windows Defender 扫描本目录：全部源码，不会触发任何告警。
- 若想进一步打包成单个 exe，注意：PyInstaller 单文件无签名 exe 容易被 Defender 启发式误报
  （与本次 uPDF 被检出同类告警），**建议保持源码 + 快捷方式运行方式**，安全且完全可控。
